# 06 修改与删除

## 修改一段经历

1. 找到文件：`grep -l "<关键词>" "<VAULT>/experiences/"*.json`
2. 读整个文件。
3. 只改用户要改的字段，其他内容原样保留（尤其是 `writings` 和 `works`，它们是用户积累下来的）。
4. 把 `updated` 换成当前时间（命令见 02-入库.md 第 4 步）。
5. 整个文件写回，校验：
   ```bash
   python3 -m json.tool "<VAULT>/experiences/<id>.json" > /dev/null && echo OK
   ```

改某个写法版本的文字或名字：在 `writings` → 对应 `type` → `versions` 里找到那个 `name`，改 `text` 或 `name`。

**不要改 `id`。** 申请记录里的段落用 id 引用经历，改了就断了。用户想「改名字」，改的是 `title`。

## 删除

**为什么不真删：** 用户可能删错。移到 `.trash/` 以后，随时能找回来。

删一段经历：

```bash
mkdir -p "<VAULT>/.trash" && mv "<VAULT>/experiences/<id>.json" "<VAULT>/.trash/$(date +%Y%m%d-%H%M%S)-<id>.json" && echo MOVED
```

如果它有作品快捷方式文件夹，也一起移走（只是快捷方式，原文件不受影响）：

```bash
test -d "<VAULT>/assets/<id>" && mv "<VAULT>/assets/<id>" "<VAULT>/.trash/$(date +%Y%m%d-%H%M%S)-assets-<id>" && echo MOVED_ASSETS
```

删一份申请记录：

```bash
mkdir -p "<VAULT>/.trash" && mv "<VAULT>/applications/<id>.json" "<VAULT>/.trash/$(date +%Y%m%d-%H%M%S)-<id>.json" && echo MOVED
```

删除前先跟用户确认一次：「要删掉『<标题>』吗？删除后会放进回收站，可以找回。」

## 找回

```bash
ls "<VAULT>/.trash/"
```

找到对应文件，`mv` 回 `experiences/` 或 `applications/`，文件名去掉前面的时间戳，改回 `<id>.json`。

## 清掉示例数据

如果启动时复制过示例，示例的 id 是：经历 `ali`、`award`、`fair`、`museum`、`retro`、`xhs`；申请记录 `d1`、`d2`。用户说「删掉示例数据」时，确认一次，然后对每个 id 做上面的删除。

## 修改个人信息、教育背景、证件照与技能（`config.json`）

右半屏前端左侧栏底部也有「个人信息 · ……」弹窗，用户随时可能在那里改过，所以**改之前先读一遍 `<VAULT>/config.json`**（铁律第 3 条）：

1. 读取 `<VAULT>/config.json`，按 `references/data-format.md` 里的 `profile` 结构更新用户要改的字段：
   - 基本信息：`name`、`headline`、`location`（城市/到岗时间）、`email`、`phone`、`links`
   - 教育背景：`education` 数组（每项含 `school`、`major`、`degree`、`time`、`details`）
   - 技能与语言：`skills` 数组（字符串列表，每条一行）
2. **如果用户发来证件照路径**：证件照体积小且导出简历必用，**直接复制一份**进数据目录，并写相对路径（别只写桌面/下载路径，防止原图被删）：
   ```bash
   mkdir -p "<VAULT>/assets" && cp "<原照片路径>" "<VAULT>/assets/portrait.<扩展名>" && echo COPIED
   ```
   然后在 `profile.photo` 里写 `"assets/portrait.<扩展名>"`。
3. 写回 `<VAULT>/config.json`，立刻校验：
   ```bash
   python3 -m json.tool "<VAULT>/config.json" > /dev/null && echo OK
   ```
4. 做完告诉用户已更新，并可顺带提醒一句：「你也可以随时在右半屏左侧栏点『个人信息』直接编辑这些内容，导出简历 PDF 时会自动带上。」
