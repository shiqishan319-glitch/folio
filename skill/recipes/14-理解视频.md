# 14 理解视频：把一段视频变成能搜到的摘要

什么时候读：挂视频作品时（`recipes/03-挂作品.md`），或者用户说「帮我看看这个视频讲了什么」「给这个视频写个摘要」。

视频通常很大，只挂了快捷方式（软链接）。以后搜索、做简历时，AI 不会每次都去打开视频，**全靠这几句摘要找到它**。所以摘要写得准，这个作品才有用。

这份菜谱大部分是建议：怎么看视频，按你的工具能力来。拿不准就走文末的「兜底步骤」。

---

## 做完是什么样（必须满足）

- 这个作品在卡片 `works` 里的 `summary`：**1–3 句纯文本，120 字以内**。
- **只写视频里能看到、听到、读到的。** 看不清、听不清的不猜，写「画面不清楚」也比编一个好。
- 视频里出现了卡片上还没有的数字或结论（比如「现场 18 个摊位」），**先问用户**要不要补进卡片的 `result`，不要自己加：视频里的数字不一定是用户自己的成果。
- 临时文件（截图、字幕）放在 `/tmp`，不要留在数据目录里。
- **不要把视频传到第三方网站或在线服务**（转码站、在线字幕工具等），除非用户明确同意。你自己的工具读取文件不算。

## 好摘要写什么

按这个顺序挑重要的写：

1. **这是什么**：答辩录屏、活动现场、作品演示、采访、路演、教学视频……
2. **谁、在哪**：用户在里面是什么身份（主讲、主持、讲解员），什么场合。
3. **展示了什么**：做了什么、讲了什么、作品长什么样。
4. **关键信息**：画面或讲话里出现的数字、结论、奖项、Logo。
5. **能当什么证据**：适合在什么申请里用（「可证明公开讲解能力」）。

对比：

- 好：「社区博物馆周末讲解录像（约 6 分钟），用户作为讲解员给一组小学生讲解青铜器展区，现场有互动问答；可证明面向儿童的讲解能力。」
- 不好：「一段讲解视频。」（太空，搜不到）
- 不好：「讲解效果很好，观众反响热烈。」（视频里看不出来的评价）

## 怎么看：按你的工具能力选

**1. 你能直接理解视频文件。** 有的模型可以直接读视频，就用它。注意看全：开头、中间、结尾都要看到，不要只凭前几秒下结论。

**2. 你能看图片。** 从视频里均匀截一组画面拼成一张图（兜底步骤 A），看这张图。画面里的字（PPT、标题、横幅、字幕条）可以直接读出来。视频很长（超过 10 分钟）时多截一些，或者分段各截一张。

**3. 关键信息在声音里**（答辩、讲解、采访）：
- 先看视频自带没有字幕轨（兜底步骤 B）；
- 用户手里可能有字幕文件（剪映导出的 `.srt`、视频平台的自动字幕），问一句；
- 你的工具能听音频，或者电脑上已经装了语音转文字工具（如 whisper），可以用；**没装的默认不装**（体积大），要装先问用户。

**4. 都不行。** 请用户用一句话说说视频内容（兜底步骤 C），这句话就是摘要的底子。

**不确定自己能不能直接看视频：** 先试一次。读不了、报错，或者描述明显对不上（比如说不出画面里有什么），就走兜底步骤。

**一次挂很多个视频：** 先列清单给用户确认，然后一个一个处理，**每处理完一个就写回**，免得中途出错前功尽弃。

## 兜底步骤（照做一定能完成）

### A. 截 9 张图拼成一张

检查工具：

```bash
which ffmpeg ffprobe > /dev/null && echo READY || echo NO_FFMPEG
```

`NO_FFMPEG`：问用户「要装 ffmpeg 吗？用来从视频里截图（macOS：`brew install ffmpeg`）」。用户不装，跳到 C。

截图（9 张均匀分布在整段视频里，拼成 3×3）：

```bash
python3 - "<视频路径>" <<'PY'
import subprocess, sys
v = sys.argv[1]
d = float(subprocess.check_output(["ffprobe", "-v", "error", "-show_entries", "format=duration", "-of", "csv=p=0", v]).strip())
subprocess.run(["ffmpeg", "-v", "error", "-y", "-i", v, "-vf", f"fps=9/{d:.2f},scale=480:-1,tile=3x3", "-frames:v", "1", "/tmp/jingliku-video.jpg"], check=True)
print(f"SHEET /tmp/jingliku-video.jpg ({d:.0f} 秒)")
PY
```

- 期望输出 `SHEET /tmp/jingliku-video.jpg (N 秒)`，然后打开这张图看。
- 长视频想多截一些：把命令里的 `9` 改成 `16`、`tile=3x3` 改成 `tile=4x4`。

### B. 取出自带字幕

```bash
ffmpeg -v error -y -i "<视频路径>" -map 0:s:0 /tmp/jingliku-video.srt 2>/dev/null && echo HAS_SUBS || echo NO_SUBS
```

`HAS_SUBS`：读 `/tmp/jingliku-video.srt`。`NO_SUBS`：视频没有字幕轨，正常，按「怎么看」第 3 条问用户有没有字幕文件。

### C. 请用户描述

「这个视频我这边看不了。你能用一句话说说它是什么吗？比如：什么场合、你在里面做什么。」

### 写回摘要

还没挂上的视频，挂的时候带上摘要（见 `recipes/03-挂作品.md` 方法一）：

```bash
python3 "<SKILL>/scripts/works.py" attach "<VAULT>" "<卡片id>" "<视频路径>" --summary "<1-3 句摘要>"
```

已经挂过的：先重新读 `<VAULT>/experiences/<卡片id>.json`，找到 `works` 里这个视频那一项，改它的 `summary`，写回后校验：

```bash
python3 -m json.tool "<VAULT>/experiences/<卡片id>.json" > /dev/null && echo OK
```

最后告诉用户摘要写了什么，问一句要不要补充。
