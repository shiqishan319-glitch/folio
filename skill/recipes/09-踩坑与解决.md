# 09 踩坑与解决

按「你看到的现象」找到对应的一节，照着做。每一条都是真实遇到过的坑。

**通用原则：** 同一个命令失败两次，就不要再原样重试第三次。把命令、完整报错和你试过的办法告诉用户，问他怎么处理。

1. 网页（右半屏）

7. 环境与安装

## 1. 网页（右半屏）

### 网页显示「连接中断，重试中…」
- **原因：** `serve.py` 停了（会话结束、电脑重启、被关掉）。
- **解决：** 运行 `python3 "<SKILL>/scripts/serve.py" --vault "<VAULT>" --ensure`。看到 `STARTED` 后几秒内，网页会自己接上，不用刷新。（重启后端口和写入口令都沿用上一次的。）

### `--ensure` 输出 `FAILED`
- 看日志：`tail -20 "<VAULT>/.serve.log"`
- 日志里有 `Permission denied`：数据目录不可写，见第 3 节「权限」。
- 日志里有 `SyntaxError` 或 `ModuleNotFoundError`：Python 版本太低（需要 3.9+），见第 7 节。
- 日志是空的：再运行一次 `--ensure`；还不行，告诉用户。

### 网页打不开，或者一片空白
- 先确认地址对：`cat "<VAULT>/.runtime.json"`，用里面的 `url`。端口可能不是 8765（被占时会自动顺延到 8766、8767……）。
- 刚打开时会先显示一两秒的加载骨架，这是正常的。
- 还是空白：让用户刷新一次。

### 网页显示「演示数据 · 不会保存」
- **原因：** 网页不是通过 `serve.py` 打开的，比如用户直接双击了 HTML 文件，或者用 `file://` 地址打开的。这时显示的是内置示例，改了也不会保存。
- **解决：** 用 `--ensure` 给出的 `http://127.0.0.1:XXXX/` 地址打开。

### 用内置浏览器打开本地 HTML 只看到「静态快照」，什么都点不了
- **原因：** 有的 AI 工具（如 Claude Code 桌面版）的内置浏览器，打开项目文件夹之外的 `file://` 页面时只显示快照。
- **解决：** 不要用 `file://`，一律用 `serve.py` 的 `http://127.0.0.1:XXXX/` 地址。

### 你改了文件，网页没变化
- 网页每 2 秒检查一次文件变化，先等几秒。
- 还没变：用 `python3 -m json.tool` 校验你改的文件。**写坏的 JSON 网页读不了**，会一直显示旧内容。
- 文件写到了别的目录：确认你改的是 `<VAULT>/experiences/` 里的文件，不是示例目录 `<SKILL>/examples/` 里的。

### 用户说「我在网页上改的东西没了」
- **原因（最常见）：** 你在用户修改之前读了文件，之后拿旧内容整段写回去，覆盖了用户的修改。
- **预防：** 铁律第 3 条：改文件前，**马上**重新读一遍，在最新内容上改。
- **补救：** 用户的修改不会进回收站，只能请用户在网页上再改一次。向用户说明原因并道歉。

### 网页提示「这条已在别处更新 · 载入最新」
- 这是正常的：用户正在网页上编辑某条内容时，你改了同一个文件。网页保留了用户的草稿，让用户自己决定是否载入你的版本。不需要你做什么，告诉用户可以点「载入最新」看你的修改。

## 2. JSON 文件

### 校验没有输出 `OK`
报错会给出行号，例如 `Expecting ',' delimiter: line 12 column 5`。看那一行和**它的上一行**：

| 原因 | 错误写法 | 正确写法 |
|---|---|---|
| 最后一项后面多了逗号 | `"tags": ["a", "b",]` | `"tags": ["a", "b"]` |
| 两项之间少了逗号 | `"role": "x"` 换行 `"tags": []` | `"role": "x",` 换行 `"tags": []` |
| 用了中文引号当 JSON 引号 | `“title”: “小红书”` | `"title": "小红书"` |
| 文字里有英文双引号 | `"text": "我说"你好""` | `"text": "我说「你好」"` |
| 文字里有直接换行 | 字符串跨了两行 | 写成一行；需要换行就写 `\n` |
| 文件开头或结尾有多余内容 | 文件前面有一句说明文字 | 文件里只能有一个 `{ … }` |

修好后再校验，直到输出 `OK`。

### 数字加了引号
`"year": "2025"` 能通过校验，但网页的时间线可能排错序。写成 `"year": 2025`。`size`、`mtime` 也是数字，不加引号。

### `null` 写成了 `"null"` 或 `None`
申请记录里没用到经历的段落，`card` 要写 `null`（小写、不加引号）。`"null"` 会被当成一段叫 null 的经历；`None` 是 Python 写法，JSON 里不合法。

### 同一段经历出现了两张卡片
- **原因：** 入库前没查重。
- **解决：** 把两张卡片的内容合并到其中一张（保留两边所有的 `writings` 和 `works`），另一张移到 `.trash/`。如果有申请记录引用了被移走的那张卡的 id，把引用改成留下的那张。
- **预防：** 入库第 1 步一定要 `grep` 查重（`recipes/02-入库.md`）。

### 改了 `id` 之后，申请记录里的段落关联断了
- **原因：** 申请记录用 `id` 引用经历。
- **解决：** 把 `id` 改回去，用户想改的是 `title`。**`id` 永远不改。**

## 3. 路径与命令

### 上一条命令里设的变量，这一条用不了
- **原因：** 很多 AI 工具每条命令都在新的 shell 里运行，`VAULT=...` 不会被记住。
- **解决：** 每条命令都写完整的绝对路径（铁律第 2 条）。

### `No such file or directory`，但文件明明在
- 路径里有空格或中文，没加英文双引号：写成 `"/Users/me/经历库/experiences/xhs.json"`。
- 用了 `~`，但它在双引号里不会展开：`"~/经历库"` 错，`"$HOME/经历库"` 或完整路径对。
- 用户给的是相对路径（如 `files/海报.jpg`）：先在当前目录、下载文件夹、桌面找（`ls`、`mdfind -name`），找不到就问用户完整路径。**不要假设，也不要自己编一个路径。**

### `Permission denied`
- 数据目录不可写：`touch "<VAULT>/.test" && rm "<VAULT>/.test" && echo WRITABLE`。没有 `WRITABLE` 就告诉用户检查文件夹权限，或者换一个数据目录。
- 不要用 `sudo` 改用户数据目录的权限，除非用户明确同意。

### macOS 和 Linux 的命令不一样
- `stat`、`date`、`sed -i` 的参数在两个系统上不同。需要文件大小、修改时间、当前时间时，用菜谱里给的 `python3` 命令，它们在哪都一样。

## 4. 作品快捷方式

### 你把作品文件复制进了数据目录
- **为什么不行：** 大文件会占两份空间，原文件改了副本也不会跟着变，而且会丢掉原文件的位置信息。
- **补救：** 把复制进来的文件移到 `.trash/`，按 `recipes/03-挂作品.md` 重新建快捷方式，在 `works` 里记录 `original`、`size`、`mtime`。

### `works` 里只写了一个文件名
- 例如 `"works": ["海报.jpg"]`。这样网页只能显示文字，打不开文件，也没法检测文件是否被移动。
- **补救：** 按 `recipes/03-挂作品.md` 改成带 `asset`、`original`、`size`、`mtime` 的对象。

### `ln: ... File exists`
- 同名快捷方式已经存在。换一个名字（如 `海报-2.jpg`），或者确认是同一个文件就直接用已有的。

### 网页上作品显示「原文件找不到了」
- 先确认网页没有显示「连接中断」。连接中断时网页不会做这个判断。
- 按 `recipes/08-检查快捷方式.md` 检查，找到新位置后重新指向。

### 网页上图片显示「暂时无法加载」
- 一般是连接中断了（见第 1 节）。网页恢复连接后会自己重新加载图片。

### Windows 上建不了软链接
- 需要管理员权限或开启「开发者模式」。做不到时，只在 `works` 里记录 `original`，不写 `asset`（网页打不开这个文件，但位置信息还在）。

## 5. 内容与写作

### 写出了卡片里没有的细节
- **这是测试中最常见的问题。** 例如卡片只写了「为儿童团体重写讲解词」，却写成了「把讲解词拆开重写，先找孩子能感同身受的切入点，再用一件物件引出故事」。
- **为什么不行：** 申请材料里的每一句话，用户都可能在面试里被追问。编出来的细节会让用户当场答不上来。
- **怎么做：** 只用卡片里的事实和数字。觉得太单薄，就在回复里**问用户**补充细节，而不是自己补。

### 字数超了
- 用菜谱里的命令数字数（中文、标点都算 1 个）。超了就删修饰语，不删事实和数字。

### 不知道用户说的是哪段经历
- 列出 2–3 个最可能的候选，让用户选。不要猜一个就直接写。

### 用户只说「你决定」
- 可以自己选，但在回复里说明你选了哪几段、为什么，方便用户纠正。

## 6. LaTeX / PDF

先看 `tail -30 /tmp/jingliku-pdf/out.log` 的输出：

| 日志里有 | 怎么办 |
|---|---|
| `File 'ctex.sty' not found` | 缺中文宏包：`tlmgr install ctex`（可能要 `sudo`，先问用户） |
| `Font ... not found` 或 `fontset` | 系统缺中文字体。macOS 一般自带；Linux 装 `fonts-noto-cjk`；先问用户 |
| `Undefined control sequence` | 模板被改坏了，或正文没经过 `fill_tex.py`。用 `fill_tex.py` 重新生成 |
| `Missing $ inserted` 或 `Misplaced alignment tab` | 正文里有特殊字符没转义。**不要手写 `.tex` 正文**，用 `fill_tex.py` 重新生成 |
| `xelatex: command not found` | 没装 LaTeX，见 `recipes/07-导出PDF.md` 第 1 步 |

- 不要绕开模板，自己用别的办法（Swift、浏览器截图、其他库）拼 PDF。效果不稳定，也很慢。没有 LaTeX 时，让用户先用网页上的「导出 PDF」按钮。
- 简历顶部显示「姓名」：`config.json` 的 `profile.name` 是空的，先问用户。
- 落款是「示例同学」：用的是示例数据的配置，问用户真实姓名，写进 `profile` 再导出。

## 7. 环境与安装

### 没有 `python3`，或版本低于 3.9
- 告诉用户需要安装，**征得同意后**再装（macOS：`brew install python`，或去 python.org 下载）。

### 想装任何东西之前
- 先告诉用户要装什么、多大、为什么需要，等用户同意。LaTeX 尤其大（几百 MB 到几 GB）。

### 后台进程被 AI 工具关掉了
- 有的工具会在命令结束时关掉它启动的子进程。`--ensure` 已经让服务脱离当前命令运行；如果还是会被关掉，就在每次处理请求前运行一次 `--ensure`（铁律第 1 条），它会自动重新拉起来。
