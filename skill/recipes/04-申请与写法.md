# 04 申请与写法：为一次申请找经历、写新版本、存回去

这是经历库最核心的用法。用户只需要做三件事：**贴要求、选、确认**。其余的你来做。

**为什么写完要存回卡片：** 下次遇到类似的申请，直接就能找到这次的写法，不用再写一遍。这是「用得越久越值钱」的来源。

---

## 第 1 步：弄清这次的要求

从用户贴来的内容里找出这几点，找不到的问一句（最多问 2 个）：

- **申请什么**：岗位 / 项目 / 奖项名称
- **写什么**：简历条目、网申某道题、面试自我介绍、评优事迹……
- **字数或长度**：如「150 字以内」「3 条 bullet」
- **语言**：中文 / 英文
- **侧重**：岗位描述里最看重的能力（如「数据分析」「沟通协调」）

## 第 2 步：找相关经历

先看有哪些经历（每行是 id、类型、标题、标签）：

```bash
python3 - "<VAULT>" <<'EOF'
import json, glob, os, sys
for f in sorted(glob.glob(os.path.join(sys.argv[1], "experiences", "*.json"))):
    try:
        c = json.load(open(f, encoding="utf-8"))
    except Exception as e:
        print("BAD_JSON", f, e); continue
    kinds = [w.get("type") for w in c.get("writings", [])]
    print(c.get("id"), "|", c.get("type"), "|", c.get("title"), "|", ",".join(c.get("tags", [])), "| 已有写法:", ",".join(kinds) or "无")
EOF
```

再用要求里的关键词搜一遍内容：

```bash
grep -l -i "<关键词>" "<VAULT>/experiences/"*.json
```

挑出最相关的 **2–4 段**，逐个读完整文件（`cat "<VAULT>/experiences/<id>.json"`）。

## 第 3 步：给用户列出候选

格式：

```
这次申请可以用这几段经历（右半屏可以看详情）：
1. 小红书 · 内容运营实习 —— 和「数据分析」直接相关；已有写法：简历条目 v1 通用、v2 偏数据
2. 校园公益市集策划 —— 体现组织协调；已有写法：简历条目 v1
3. ……
你想用哪几段？要基于哪个已有版本改，还是重新写？
```

等用户选。用户说「你决定」就用你排的前几个。

## 第 4 步：写新版本

规则：

- **只用卡片里有的事实和数字，不编造。** 缺数字就写定性描述，并提醒用户可以补。
- 按要求的侧重调整顺序和用词：先写和岗位最相关的那部分。
- 简历条目：动词开头，一句话，有结果和数字。例：「搭建话题数据复盘表，按周跟踪 5 项指标，推动话题周均互动量提升约 30%。」
- 网申/开放题：第一人称，有情境、行动、结果、收获。
- 字数限制要严格遵守。中文字数用这个命令数（标点也算）：

```bash
python3 -c "import sys;print(len(sys.argv[1]))" "<你写的文字>"
```

把写好的内容发给用户看。用户要改就改，直到他满意。

## 第 5 步：存回卡片（用户确认后）

用户说「可以」「就这个」之后，存回去。

1. 读 `<VAULT>/experiences/<id>.json`。
2. 在 `writings` 里找 `type` 相同的一组：
   - **找到了**：在它的 `versions` 数组末尾加一个版本。
   - **没找到**：在 `writings` 末尾新建一组。
3. 版本名 `name` 的格式：`v<序号> <场景或特点>`。序号 = 这组已有版本数 + 1。例：`v3 英文`、`v2 偏数据 · 150 字`、`v4 字节跳动 PM`。
4. 更新 `updated`，写回文件，校验。

写法类型（`type`）尽量用这些名字，方便以后找：`简历条目`、`英文简历条目`、`网申短描述`、`网申长回答`、`面试自我介绍`、`评优事迹`、`个人陈述段落`。

**改之前和改之后的例子：**

改之前：
```json
"writings": [
  {"type": "简历条目", "versions": [
    {"name": "v1 通用", "text": "负责垂类话题选题与数据复盘……"}
  ]}
]
```

用户确认了一条英文版，改之后：
```json
"writings": [
  {"type": "简历条目", "versions": [
    {"name": "v1 通用", "text": "负责垂类话题选题与数据复盘……"}
  ]},
  {"type": "英文简历条目", "versions": [
    {"name": "v1 内容运营岗", "text": "Ran weekly data reviews for a content vertical, lifting average engagement by ~30%."}
  ]}
]
```

校验：

```bash
python3 -m json.tool "<VAULT>/experiences/<id>.json" > /dev/null && echo OK
```

## 第 6 步：告诉用户

「已存回：小红书实习 → 英文简历条目 v1。下次申请类似岗位时可以直接用。」

如果这次用户要的是**一整篇文档**（自荐信、动机信），改看 `recipes/05-整篇文档.md`。
