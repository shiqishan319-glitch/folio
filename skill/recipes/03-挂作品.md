# 03 挂作品：给经历加上文件或链接

作品是一段经历的证据：照片、视频、PPT、PDF、压缩包、网页链接。

**为什么用「分层存储 + 轻量语义索引」：**
- **在线链接（`kind: "link"`）**：飞书、Notion、GitHub、Figma 等只记 URL，0 体积。
- **≤ 5 MB 轻文件（`mode: "copy"`）**：证件照、获奖证书、核心截图直接复制进 `<VAULT>/assets/<卡片id>/`，体积可控且迁移/同步永不丢失。
- **> 5 MB 大文件与视频（`mode: "link"` + `summary`）**：视频、大型 `.pptx`、压缩包等只放**软链接**（快捷方式）不占库空间；**同时必写 1–3 句 `summary` 纯文本摘要**，让前端搜索框和 AI 不用打开大文件就能秒级命中（并记下 `sha256` 指纹，日后移动可一键 `relink` 找回）。

---

## 方法一（推荐）：一行脚本自动分流挂载

需要：卡片 id（如 `xhs-2025`）和原文件路径。若能看懂文件内容（截图、PPT、PDF、视频介绍），先提炼 1–3 句 `--summary`：

```bash
python3 "<SKILL>/scripts/works.py" attach "<VAULT>" "<卡片id>" "<原文件路径>" --summary "<1-3句核心内容摘要>"
```

- 默认 `--mode auto` 会按 5 MB 与文件类型自动选 `copy` 或 `link`，计算 `sha256` 指纹，并自动写入卡片 `works[]`、更新 `updated`（若要强制指定，可加 `--mode copy` 或 `--mode link`；自定义显示名加 `--label "<显示名>"`）。
- 若需盘点全库作品体积、断链与摘要覆盖情况：
  ```bash
  python3 "<SKILL>/scripts/works.py" audit "<VAULT>"
  ```

## 方法二：手动步骤（无软链接权限或需要细粒度检查时）

需要：卡片 id（如 `xhs-2025`）和原文件的完整路径（用户给的路径里有 `~` 也可以）。

### 第 1 步：确认文件存在，拿到它的信息

```bash
python3 - "<原文件路径>" <<'EOF'
import json, os, sys
p = os.path.abspath(os.path.expanduser(sys.argv[1]))
if not os.path.exists(p):
    print("NOT_FOUND", p); sys.exit(1)
s = os.stat(p)
print(json.dumps({"original": p, "name": os.path.basename(p), "size": s.st_size,
                  "mtime": int(s.st_mtime), "is_dir": os.path.isdir(p)}, ensure_ascii=False))
EOF
```

- 输出 `NOT_FOUND`：告诉用户找不到这个文件，请他确认路径（可以把文件拖进对话框得到路径）。
- 正常输出一行 JSON：记下 `original`、`name`、`size`、`mtime`。

### 第 2 步：建快捷方式

```bash
mkdir -p "<VAULT>/assets/<卡片id>" && ln -s "<original>" "<VAULT>/assets/<卡片id>/<name>" && echo LINKED
```

- 提示 `File exists`：同名的快捷方式已经有了。把 `<name>` 改成 `名字-2.扩展名` 再运行。
- Windows 上建软链接可能需要管理员权限；失败就跳过这一步，第 3 步里不写 `asset`、`mode` 两个字段（前端打不开文件，但会记住原路径）。

### 第 3 步：判断类型

按扩展名选 `kind`：

| 扩展名 | kind |
|---|---|
| .jpg .jpeg .png .gif .heic .webp | `image` |
| .mp4 .mov .m4v .webm | `video` |
| .pdf | `pdf` |
| .ppt .pptx .key | `slides` |
| .doc .docx .pages .md .txt | `document` |
| .zip .rar .7z | `archive` |
| 文件夹 | `folder` |
| 其他 | `file` |

### 第 4 步：写进卡片

读 `<VAULT>/experiences/<卡片id>.json`，在 `works` 数组末尾加一项（数组里原来的内容保留）：

```json
{"label": "<给用户看的名字，默认用文件名>", "kind": "<第 3 步>", "asset": "<卡片id>/<name>", "mode": "link", "original": "<original>", "size": <size 数字>, "mtime": <mtime 数字>}
```

例：

```json
"works": [
  "周报截图 ×3",
  {"label": "复盘汇报.pptx", "kind": "slides", "asset": "xhs-2025/复盘汇报.pptx", "mode": "link", "original": "/Users/me/Documents/复盘汇报.pptx", "size": 2483912, "mtime": 1757212800}
]
```

更新 `updated` 时间（命令见 02-入库.md 第 4 步），写回文件，然后校验：

```bash
python3 -m json.tool "<VAULT>/experiences/<卡片id>.json" > /dev/null && echo OK
```

## 用户要求复制一份进来

把第 2 步换成复制，第 4 步里 `"mode": "copy"`：

```bash
mkdir -p "<VAULT>/assets/<卡片id>" && cp -R "<original>" "<VAULT>/assets/<卡片id>/<name>" && echo COPIED
```

## 挂一个网页链接

不需要建快捷方式，直接在 `works` 里加：

```json
{"label": "<名字>", "kind": "link", "url": "<https://...>"}
```

写回、更新 `updated`、校验。

## 最后

告诉用户：「已把 <文件名> 挂到 <经历标题> 下（只建了快捷方式，原文件没动）。」
