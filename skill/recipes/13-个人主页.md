# 13 个人主页：从经历库生成一个能直接打开的网页

用户说「帮我做个个人主页 / 个人网页 / 作品集页面」时，读这个文件。

生成的是**一个 HTML 文件**：所有样式都在文件里，双击就能在浏览器打开，手机上也能看，自动适配深色模式。内容和简历用同一套数据（个人信息 + 经历卡片里的写法）。

## 第 1 步：问两件事（一次问完）

1. **用哪份内容？** 有简历的话推荐用一份简历（「就用投内容运营那份」），页面的分节、顺序、写法版本都跟它一样。没说就把所有经历都放上。
2. **要不要显示电话？** 网页通常是公开的，默认**不放电话**，只放城市、邮箱和链接。

看看有哪些简历：

```bash
ls "<VAULT>/resumes/" 2>/dev/null || echo NO_RESUMES
```

## 第 2 步：生成

用一份简历（`<简历id>` 是 `resumes/` 里的文件名，不带 `.json`）：

```bash
python3 "<SKILL>/scripts/fill_html.py" site "<VAULT>" "$HOME/Downloads/<姓名>-个人主页.html" --from "<简历id>"
```

所有经历：

```bash
python3 "<SKILL>/scripts/fill_html.py" site "<VAULT>" "$HOME/Downloads/<姓名>-个人主页.html"
```

用户要显示电话，就在命令末尾加 `--phone`。

- 期望结果：打印出文件路径。
- 报错 `No such file`：简历 id 写错了，用第 1 步的命令看正确的名字。

## 第 3 步：告诉用户

「个人主页已经生成：下载/<姓名>-个人主页.html，双击就能打开。想改内容，改经历卡片或那份简历后再生成一次就行。」

如果用户想放到网上让别人访问，提一句即可（不用展开）：「可以把这个文件改名为 `index.html`，放进一个 GitHub 仓库并打开 GitHub Pages，就有一个公开网址了。」
