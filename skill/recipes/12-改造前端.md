# 12 改造前端：按用户的习惯改右半屏

用户说「把右边改成深色」「字大一点」「在左栏加个投递统计」「卡片上显示字数」时，读这个文件。

**只写两个文件，都放在数据目录里：**

| 文件 | 管什么 |
|---|---|
| `<VAULT>/custom.css` | 样式：颜色、字号、间距、隐藏某个区域 |
| `<VAULT>/custom.js` | 小功能：在页面上加一块信息、一个按钮 |

页面打开时发现它们就会加载。**不要改 `<SKILL>/app/index.html`**：那是 skill 的文件，一更新就被覆盖（git 安装的还会因为本地改动卡住更新）。用户的改动放在数据目录里，更新不会动它；想撤销，删掉或改名这个文件，刷新就复原。

---

## 改样式：`custom.css`

页面的颜色都是 CSS 变量，改变量最省事。文件已存在就先读一遍，在末尾追加，不要覆盖用户之前的改动。

```css
/* 例：主色换成绿色，正文大一号 */
:root { --accent: #0f9f6e; --accent-solid: #0f9f6e; --accent-solid-2: #22c08a; }
body { font-size: 14px; }
```

常用的区域：

| 选择器 | 是什么 |
|---|---|
| `.col.side` | 左栏（类型、简历、申请信） |
| `.col.list` | 中间时间线；`.card` 是一张经历卡片 |
| `.col.detail` | 右边详情；`.tile` 是事实 / 结果 / 思考 / 作品四块 |
| `.rp` | 简历编辑器里的那张纸（只影响右半屏预览，**不影响导出的 PDF**） |

深色：不用写 CSS，在 `custom.js` 里加一行 `document.documentElement.dataset.theme = 'dark';`（`'light'` 是浅色）。

## 加小功能：`custom.js`

页面每次刷新内容都会整块重画，所以**往页面里加东西要放进 `JL.afterRender(...)`**，每次重画后它会再跑一遍。`window.JL` 里能用的：

| 写法 | 作用 |
|---|---|
| `JL.cards` | 所有经历卡片（数组，字段见 `references/data-format.md`） |
| `JL.resumes` / `JL.docs` | 所有简历 / 申请信 |
| `JL.profile` | 个人信息 |
| `JL.afterRender(fn)` | 每次重画后运行 `fn` |
| `JL.toast('文字')` | 底部弹一句提示 |

**只读这些数据，不要改它们。** 要改经历、简历的内容，照其他菜谱直接改 JSON 文件。

例：左栏底部显示投递统计。

```js
JL.afterRender(() => {
  const side = document.querySelector('.col.side');
  if (!side || side.querySelector('.my-stats')) return;   // 左栏收起了，或者已经加过了
  const sent = JL.resumes.filter(r => r.status === '已投递').length;
  const box = document.createElement('div');
  box.className = 'my-stats';
  box.style.cssText = 'margin:12px 6px;padding:10px 12px;border-radius:12px;background:var(--sunk);font-size:12.5px';
  box.textContent = `已投递 ${sent} 份 · 草稿 ${JL.resumes.length - sent} 份`;
  side.querySelector('.sidefoot').before(box);
});
```

要点：
- 加的元素给一个自己的类名（如 `my-stats`），先检查有没有加过，避免重复。
- 找不到目标区域就直接 `return`（窄屏时左栏是收起的）。

## 写完以后

有 `node` 就先检查语法：

```bash
node --check "<VAULT>/custom.js" && echo OK
```

告诉用户：「改好了，刷新一下右半屏就能看到。不喜欢的话说一声，我把它删掉。」

`custom.js` 出错时，页面底部会提示「custom.js 出错了：……」，其他功能照常。按提示修好，或把文件改名成 `custom.js.off` 先停用。

**撤销：**

```bash
mkdir -p "<VAULT>/.trash" && mv "<VAULT>/custom.js" "<VAULT>/.trash/$(date +%Y%m%d-%H%M%S)-custom.js" && echo MOVED
```

（`custom.css` 同理。）

**分享给朋友：** 把这两个文件发给对方，放进他的数据目录就行。

**收到别人发来的 `custom.js`：** 放进去之前先读一遍，跟用户说明它会做什么。它应该只读 `JL` 的数据、往页面上加东西；出现 `fetch`、`XMLHttpRequest`、`PUT`、`DELETE`，或者改 `JL.cards` 之类的数据，就先问用户。（页面本身只允许和本机的 `serve.py` 通信，脚本没法把数据发到外网；但它能在页面里做的事，和页面本身一样多。）
